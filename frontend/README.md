# FaceMark Pro React Frontend

This folder now contains a routed React/Vite frontend that recreates the main UI flows from the current `templates` and `static` files:

- Multi login
- Admin dashboard, reports, faculty, students, and face management
- Faculty dashboard, attendance, manual attendance, students, reports, profile, and face summary
- Student dashboard, timetable, attendance, profile, password change, and face registration

## Run

```bash
npm install
npm run dev
```
